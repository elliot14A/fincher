# Fincher Quality & Pre-Flight Checklist

Before completing any task or tagging a milestone, run through this checklist:

---

## 1. Static Quality & Tests
- [ ] `go build ./...` passes with 0 errors.
- [ ] `go vet ./...` reports 0 issues.
- [ ] `golangci-lint run` passes cleanly.
- [ ] `go test -v ./internal/policy/... -race` verifies all policy evaluation gates.
- [ ] `go test -v ./internal/turso/... -race` validates SQLite migrations and concurrent WAL operations.

---

## 2. Invariant Adherence
- [ ] **Read-Only Agents**: No `INSERT`/`UPDATE`/`DELETE` queries generated by agents; all mutations owned by application layer.
- [ ] **Deterministic Policy Enforcement**: AI proposals pass through `internal/policy/engine.go` without bypass.
- [ ] **Closed-Loop Progression**: All executed actions emit corresponding downstream events.
- [ ] **Audit Trail Completeness**: Every agent step and policy decision writes an `AuditLogEntry`.

---

## 3. Container & Infrastructure
- [ ] `docker compose config` is valid.
- [ ] ClickHouse starts and creates tables from `data/clickhouse/schema.sql`.
- [ ] `@clickhouse/mcp-server` starts and connects to ClickHouse without authentication failures.
